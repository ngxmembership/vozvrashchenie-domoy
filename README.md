# Возвращение домой — игра в семи снах

Браузерная игра по мотивам сайта [as-gard.com](https://www.as-gard.com) и форума
[2112.forum2x2.ru](https://2112.forum2x2.ru). Семь глав — семь разных механик,
каждая по своему разделу сайта.

| # | Глава | Механика |
|---|-------|----------|
| 1 | Что происходит? | **Скорлупа** — круговой арканоид: пробейте скорлупу и освободите светило |
| 2 | Сжатый в каплю океан | **Круг** — обводите «восьмёрки» ∞ идеальным кругом (оценка точности) |
| 3 | Устройство планеты | **Декорации** — линза показывает изнанку мира, найдите картонные макеты |
| 4 | Ловушки матрицы | **Лабиринт** во тьме: ключи, охотящиеся крюки, фальшивые двери |
| 5 | Магия | **Уплотнение** — рой энергии собирается в руны силой мысли |
| 6 | Как мы сюда попадали | **Паутина** — пауки, ловушки, слабые и сильные волны |
| 7 | Занавес | **Кроличья нора** — падение + бесконечный режим |

Также: карта-гроздь, звёзды, Книга памяти (42 цитаты), 13 «озарений»,
«сон дня» с очками x2, серия дней, синтезированный звук (WebAudio),
частицы, тряска экрана, hit-stop. Прогресс хранится в localStorage.

## Управление

- Мышь / палец — основное управление
- WASD / стрелки — движение, пробел — действие / волна
- Esc — пауза

## Запуск

~~~bash
npm install
npm run dev     # разработка
npm run build   # сборка в dist/
~~~

При пуше в main игра автоматически публикуется на GitHub Pages
(workflow .github/workflows/deploy.yml).
